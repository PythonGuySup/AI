# Часто задаваемые вопросы

**Как создать задачу?**
Скажите: "создай задачу <название>"

**Как посмотреть список задач?**
Скажите: "покажи задачи"

**Как удалить задачу?**
Скажите: "удали задачу < ID>"

**Что такое Redis и зачем он нужен?**
Redis — это in-memory база данных. В проекте используется для кэширования списка задач (ускоряет GET /tasks) и для хранения счётчиков rate limiter.

**Что такое Kafka?**
Kafka — это распределённый брокер сообщений. В проекте используется для асинхронной доставки событий от event-service к notification-service.

**Почему используется PostgreSQL, а не другая БД?**
PostgreSQL обеспечивает ACID-транзакции, целостность данных и удобство работы с реляционной моделью задач.
