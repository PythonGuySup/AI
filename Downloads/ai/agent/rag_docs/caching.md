# Кэширование в проекте

Redis используется для кэширования результатов GET /tasks. Ключ: "tasks:all", TTL = 30 секунд. При создании или удалении задачи кэш инвалидируется (очищается).

Rate limiter (slowapi) также использует Redis для хранения счётчиков запросов. Лимиты: 5 запросов/сек на POST и DELETE, 10 запросов/сек на GET.

Преимущества: снижение нагрузки на PostgreSQL, ускорение ответа (<1 мс из кэша против 5-15 мс из БД).
